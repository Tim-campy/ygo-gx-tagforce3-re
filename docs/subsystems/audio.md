### Findings from the audio batch

Source: the six packs of this round (231 functions: the BOOT.BIN sound driver `0x08818778`-`0x088722f4`, the duel cut-in voice code of `rel_duel_draw`, the duel voice queue of `rel_duel_mgr`, and the BGM code of `rel_field`, `rel_story`, `rel_title`). Everything below is read from the Ghidra decompilation; nothing was traced in PPSSPP. Confidence is high unless stated.

#### Extractor-relevant facts (summary)

- **The per-sound attribute table lives in the "SHDS" header, not in `psp_snddat.bin`.** `audio_bind_sound_header` (`0x08867938`) binds a header with magic `"SHDS"` (`0x53444853`) and version `u16 +0x08 & 0xfff0 == 0x50`. Bank count = `u16 +0x0c` + `u16 +0x10`; sound-id count = bank count + `u16 +0x0e`; `u16 +0x0c` is the "split" (number of music ids; ids below it are BGM). Tables start at `+0x34`, back to back: `u32 attr[id count]`, `16-byte bank record[bank count]`, `u32 bank offset[bank count]`, `u16 first id[bank count]`. The last two match `sound.md`'s static tables `0x0889cf20` / `0x0889da80`, and the "16-byte records just before `0x0889cf20`" are the bank records, so the header very probably sits in BOOT.BIN at `0x0889cf20 - 728*16 - ids*4 - 0x34` (hypothesis, medium: the caller `system_load_audio_modules` was not in these packs). An extractor that wants per-sound types, priorities, 3D flags and voice flags must read this attribute table.
- **Attribute word (4 bytes per global sound id):**
  - byte 0 low nibble = sound type (key bits 16-19): 0 SAS note sequence, 1 sound script (frame-timed event list), 2-3 one-shot PS-ADPCM on sceSas, 4 and 5 ATRAC streams. 4 vs 5 is ATRAC3plus vs ATRAC3 (hypothesis, medium-high: the driver keeps per-type decoder limits in bytes `0x08dd3124`/`0x08dd3125`, set together by `sceAtracReinit(4, 1)`, whose arguments are the AT3+ and AT3 id counts).
  - byte 0 bit `0x20`: voice category (key `| 0x200000`); bit `0x40`: two ADPCM layers (attr "mode 2", the second layer is keyed on with tag 1); bit `0x80`: may not steal other sounds' SAS voices.
  - byte 1: priority (a new sound cannot evict a playing one with a higher byte 1; copied to object `+0x20e`).
  - byte 2: maximum simultaneous instances (sound effects).
  - byte 3: bit `0x01` no 3D positioning, `0x02` no distance volume, `0x04` no 3D pan, `0x08` Doppler pitch, `0x10` ignore mix presets/pause groups, `0x20` no reverb send, `0x80` decoded but not mixed (streams).
- **Cue fields as the driver reads them** (`sound.md` offsets): `+0x00` signed volume (`x 0x1021 >> 7` gives 0..0x1000); `+0x02` duck level: while a sound with a positive value plays, BGM is scaled to `((15 - v) x 0x1112) >> 4` / 0x1000 (smallest value wins, 150 ms fades; `audio_update_bgm_ducking`); `+0x03` retrigger lock (x 6 mixer grains during which the same sound effect cannot restart); `+0x04` volume/stop group (selectors `0xfffffe00 | group`; groups 0xc8-0xca are used by `audio_stop_sound_with_groups_2` and the sound scripts); `+0x05` row of the mix-preset table; `+0x07` 3D range-record index (it is the high byte of the `u16` layer count at `+0x06`, so 0 on the disc); `+0x08` target; `+0x0c`/`+0x0d` echo send level/delay for streams (copied to object `+0xe0/+0xe1`; 0 on the disc); **`+0x10` random-variation count** and `+0x11` sequential-cycle count (below); `+0x12..+0x17` signed min/max pairs (random volume offset, random transpose, random fine pitch; all 0 on the disc); `+0x18` duration (ms); `+0x1c` minimum audible level for culling positional sounds (`x 0x102 >> 8`); `+0x1d` exclusive group for instance limits; `+0x1e` read by a getter, meaning unknown.
- **Cue `+0x10` is a random-variation count** (`audio_start_sound`, `0x0886b37c`): when a sound effect or voice (key bit `0x100000`) with `+0x10 = k > 0` is played without flag 4, the driver plays cue `N + r` with `r = random(k)`, never repeating the previous pick of that (owner, id) pair (32-entry history at `0x08dd3010`); a non-zero `+0x11` replaces the random pick by a counter cycling through `+0x11` values. `audio_play_se_unlimited` passes flag 4 and plays cue N itself. The disc has values 2-6 in about 4,670 cues (30,779 - 26,110 per `sound.md`), so **the port must reproduce the variation, not just play the requested cue** (confidence medium-high: logic read from a 2.6 KB function).
- **Envelope record (24 bytes) fields used by `audio_key_on_sas_voice`**: `+0x00` volume, `+0x01` pan, `+0x04 u16` ADSR1 and `+0x06 u16` ADSR2 passed to `sceSasSetSimpleADSR` (confirms `sound.md`'s hypothesis that `0x1FE0800F` is ADSR1 `0x800F` / ADSR2 `0x1FE0`), `+0x08` bit 0 = loop flag passed to `sceSasSetVoice` (the four looping samples), `+0x09` reverb send level, `+0x0c` signed transpose (semitones), `+0x0d` root note, `+0x12/+0x13` random semitone range, `+0x14/+0x15` random fine range (1/128 semitone).
- **ADPCM sample header** (`u32 length, u16 pitch, u16 rate, data`): the driver passes `data` and `length` to `sceSasSetVoice` and uses the `u16 pitch` (rate x 4096 / 44100) as the sceSas pitch at the root note; final pitch = sample pitch x note factor (`audio_note_to_sas_pitch`: semitone table `u16 0x08916c70`, fine table `u16 0x08916b70`, 0x1000 at the root) x pitch bend x the object's pitch fader, clamped to `0xffff`. So playing a layer at its stored rate is correct for an unpitched sound.
- **RIFF waves**: `audio_start_atrac_voice` hands the length-prefixed RIFF at `bank + header[+0x14] + cue[+0x08]` (the `u32` length, then the RIFF) to `sceAtracSetDataAndGetID` unchanged and calls `sceAtracSetLoopNum(id, -1)`: **every wave with a `smpl` loop loops forever**, including the 11 effect waves of banks 714-723 (answers `sound.md`'s open question, confidence medium-high). A stop request (`audio_key_off_sound`, object `+0xe3`) switches to `sceAtracSetLoopNum(id, 0)` so the stream plays out to its end. Loop points come from `sceAtracGetSoundSample` (end, loop start, loop end), i.e. from the `smpl` chunk.
- **Bank loading**: `audio_load_bank` reads a whole bank (size = bank record `+0x08`) at `u32 offset[bank] + 0x08dd3114` (stream base, set by `audio_set_stream_source`) from `psp_snddat.bin` through the read hook (`audio_read_sound_data_async`, container root 7). Music ids equal their bank ids (0-47, one cue per bank), so `audio_load_track(n)` / `audio_play_track_with_fade(n)` load and play music bank n.
- **Bank usage found in the modules** (resolves part of `sound.md`'s "banks 709-711" question): title loads `0x2c8` (712) and, except in one boot path, `0x2c5` (709) and `0x2cf` (719); free roam loads `0x2c6`, `0x2c7` (710, 711), `0x2c8`, `0x2c9`, `0x2cb`, `0x2cc`, `0x2cd` and `0x2d7` (727); the duel loads `0x2cf` plus music bank 9 (set-up byte `+0x194` 4 or 5) or 8, and the duellists' voice banks.
- **Output format**: 44,100 Hz stereo s16, grains of 256 frames (`0x400` bytes, double-buffered at `0x08dcdc80`), one sceAudio channel (index 2, `0x100` samples). The driver's time unit ("tick") is one grain: milliseconds convert as `ms x 10 / 58`; negative time arguments are ticks.

#### Driver structure (BOOT.BIN)

- Globals: header `0x08dd3004`, id count `0x08dd3008`, bank count `0x08dd300c`, flags `0x08dd3110` (`0x2000` stream source set, `0x4000` 3D on, `0x8000` initialised), last error `0x08dd3120` (1 bank missing, 2 no slot, 4 retrigger blocked, 8 load failed, 0x10 bad type, 0x20 culled, 0x80 bad id).
- Sound objects: 34 x `0x214` bytes at `0x08dce95c`. Slots 0-3 BGM (types 0-3), 4-0x1b sound effects/voices (types 0-3), 0x1c-0x21 ATRAC streams (types 4-5; stream rings `0x08dd3200 + (slot-0x1c) x 0x6000`). Handle = `0x20000000 | slot << 16 | id`. Fields: `+0x14` stop callback, `+0x18` requested id, `+0x1c` key, `+0x24` grain counter, `+0x28` flags (`0x02` pause transition started, `0x04` pausing, `0x08` pause/resume pending, `0x10` paused, `0x20` level meter on, `0x40` pending restart, `0x80` fading out, `0x200` faders dirty, `0x400` positioned, `0x800` unload bank on stop, `0x1000` held, `0x2000` waiting for bank, `0x4000` started, `0x8000` in use), `+0x2c` start time, `+0x30` slot (-1 free), `+0x31` retrigger counter, `+0x32` age rank, `+0x33` type, `+0x34..+0x4c` 3D position/follow pointer/range, eight 10-byte faders at `+0x50` (0 category volume, 1 fade-out, 2 pause fade, 3 volume, 4 unused here, 5 secondary/3D distance volume, 6 pan, 7 pitch), `+0xa0` cue volume, `+0xa2` computed volume, type-specific block `+0xa4..+0xec`, sequence tracks `+0xbc` (6 x `0x2c`), note slots `+0x1c4` (6 x 12), `+0x20e` priority, `+0x210` pause time, `+0x212` owner.
- Fader layout (**correction**): 16-bit fader = `s16 target +0`, `s16 current +2`, `u8 fraction +4` (6 bits), `s16 step +6`, `s16 remaining ticks +8`. The 2026-10-31 rows of `audio_fader16_init` and `audio_is_bgm_volume_fading` call `+0` "current" and `+2` "target"; `audio_fader16_set_target` writes the target to `+0` and `audio_fader16_step` moves `+2` toward `+0`. The 8-bit fader is the same with bytes `+0` target, `+1` current, `+2` fraction, `s16 +4` step, `s16 +6` ticks.
- Lists (intrusive, `audio_list_*`): all sounds `0x08dce608` (link offset 8), types 0-1 `0x08dce5e4`, types 2-3 `0x08dce5fc`, streams `0x08dce5f0`.
- SAS voices: 32 records of 24 bytes at `0x08dce65c` (`+0` owner, `+4` flags: `0x04` released, `0x08` keyed off, `0x10` params dirty, `0x20` legato, `0x40` keyed on; `+5` voice, `+6` layer tag, `+7` velocity, `+8` serial for oldest-first stealing, `+0x0a` release rate, `+0x0c` sample pitch, `+0x10` note pitch, `+0x12` bend, `+0x14` envelope volume, `+0x15` volume, `+0x16` envelope pan, `+0x17` pan); allocation mask `0x08dce658`.
- Threads: `snd_thread_main` (`audio_mixer_thread`, priority 0x10) mixes each grain, keys SAS voices on/off, decodes ATRAC streams with `sceAtracDecodeData`, mixes them, runs the echo ring and the output effect and outputs; `snd_thread_seq` (`audio_sas_voice_thread`, priority 0x11) keys on new one-shot ADPCM sounds and steps the note sequencer; they hand over through event flag `SndSeqEvt` (bit 1 = mixer to sequencer, bit 0x80 = done). Semaphores: `SndSema 0x08dce654` (object lists), `SndAtracDecodeSema 0x08dce64c`, `SndLoadSema 0x08dce650`, `SndSeqSema 0x08dce648`.
- `audio_update_frame` (game frame) starts decoders, handles the pause state machine, runs sound scripts, retires finished sounds and restarts pending ones; `audio_stop_sound` restarts pending BGM slots and pending voices after a stop.
- Volumes: master fader `0x08dce620` (0x4000 = full, output `x 2`), category volumes `u16 0x08dce62c[3]` (BGM, sound effects, voices; from the option bytes, `level x 8 + 7`), duck fader `0x08dce614` (BGM only). Mix presets (`audio_push_mix_preset`, 8-deep stack at `0x08dc19d4`) are tables of 12-byte signed rows indexed by cue `+5`, column chosen by the caller, terminated by a row starting with `0xfe`; mode bit 0 of the same API pauses (fade fader 2 to 0 over the given time, then pause the SAS voices / remember the stream position) and clears to resume.
- Output effects (`audio_set_output_effect`): 1 a stereo filter (not decoded, skipped), 2 echo through a `0xc000`-byte VPL ring of `0x3000` frames, delay = level byte x `0x5e` frames, decaying by half per pass, 3 moving-average low-pass whose width follows the 8-bit fader `0x08dce5d0`. Byte `0x08dce5cd` selects where it applies (0x10 on the SAS output, 0x20 before the SAS mix, 0x30 after). Streams also have their own echo send (`+0xe0` level, `+0xe1` delay) into the ring `0x08dc1a84`. No caller of `audio_set_output_effect` was in these packs.
- 3D: listener matrix `0x08dd3190`, range records of `0x1c` bytes (`float near, mid, far; u16 mid level, far level; float +0x10` reference distance) in a table `0x08dd313c` (count `0x08dd3164`) or the default record `0x08dd3140`; attenuation is piecewise linear (`audio_compute_distance_attenuation`); pan from `atan2`; Doppler pitch for attribute bit `0x08`. No game caller of the 3D API was in these packs.
- Sequencer (type 0) and sound scripts (type 1) exist in code; on the disc every cue's `+0x0c` is 0 and the area after the envelope table is zero, so no bank seems to carry sequence or script data (hypothesis, medium; it depends on which ids the attribute table marks type 0/1). Sequence opcodes: notes below 0x80 (variable-length velocity and duration), 0x82 call, 0x83 jump, 0x88 end, 0x89 wait, 0x8a layer, 0x8b volume, 0x8c pan, 0x8d bend, 0x8e return, 0x8f bend range, 0x94 tempo, 0x95/0x96 ADSR masks, 0x99 portamento time, 0x9a portamento note, 0x9b legato. Script events: `u16 frame, u8 op` with ops 1-7 (start/re-sync stream, play, play with callback, stop, set volume, end, abort), frames at 60 Hz, stream re-sync at 44.1 samples per ms.

#### Duel voices and cut-ins

- Duellist entries of the duel set-up block (`deck_get_duel_setup_buffer`, `0x1ac` bytes from `+0x1a4`): `+0x1a4 u16` character, `+0x1a6 u16` variant, `+0x1b4` voice-set bank in use, `+0x1b8` extra (small) bank in use. Set-up `+0x192`: 1 two duellists, 2 tag duel (4 duellists); `+0x190` values 2 and 3 disable voices; `+0x194` 4/5 select duel music bank 9.
- Loading: `audio_load_duellist_voice_banks` loads `audio_get_duel_voice_bank` (voice set + 0 vs player, + 1 between two NPCs, + 2 in tag duels) and extra bank + 0 (voice ids 0-1); `audio_voice_queue_process` op 0x0c releases the extra banks when the duel BGM starts; at the end `audio_voice_on_duel_end` releases the voice set and loads extra bank + 1 for the winner (voice id 2); the loser/draw offsets are hidden register arguments (2 and 3 expected, hypothesis medium).
- Cut-in voice selection (`rel_duel_draw`): the cut-in voice event and flags are set through `0x0989d4c0(event, flags)` (default-named in these packs; identified by its arguments, hypothesis high). `audio_select_cutin_voices_standard` (named characters, 145/149-cue sets) and `audio_select_cutin_voices_special` (generic students, 52-cue sets) turn the event into up to 4 x 4 voice ids; the event tables are `0x098cc6e0` (0x20 entries) and `0x098cc860` (0x1f entries) of `{event, first id, last id}`. This answers `sound.md`'s question about the 52-cue sets: their voice ids run 5-0x34 (cues 0-47) with the per-event assignment written in the row of `0x0984076c`. Event numbers seen: 0/1 (start), 2 own turn (flags bit 0 ahead, bit 1 behind), 3/4 draw (same mood bits), 5/6/8 activations, 7, 9 and 0x0b-0x10/0x1f summons by type, 0x11 attack on a monster, 0x12 direct attack, 0x13 end of turn, 0x14-0x16 damage levels, 0x17 lethal damage, 0x18, 0x19 win, 0x1a lose, 0x1b draw, 0x1c, 0x1d key-card moved, 0x1e special reaction. Flags: 4 key card, 0x20/0x40 activation types, 0x80 strong attack, 0x100/0x200 summon details, 0x400-0x2000 multi-target attack (character 5 only, voice ids 0x96-0x99 = the 149-cue set's extra lines).
- Duel voice queue (`rel_duel_mgr`, 16 x 16 bytes at `0x08eba06c`): opcodes listed in the row of `audio_voice_queue_process`; the UI event handlers (`audio_voice_on_*`) push sequences like {1 cut-in, 0x0f voice event, 2 wait, 4 talk off}.
- Duel BGM mood: tracks `u16 0x08eba1a0` normal, `0x08eba1a2` ahead, `0x08eba1a4` behind, `0x08eba1a6/a8/aa` results (local win, remote win, draw); switching rules in the row of `audio_voice_update_duel_mood` (life-point thresholds 2000/3000/4000 and AI battle dominance).

#### Free roam and title BGM

- Location BGM (`audio_get_location_bgm`): music ids 0x0a-0x14 by location; time slots 7+ use 0x14; locations 7-0x0f and 0x1c play at level 0x60, others 0x80. Story BGM state block `*(0x08ecea50)`: word 0 current, word 1 requested, word 2 level.
- Points-change jingles 0x7a11-0x7a16 by size of the change; field sound effects go through `audio_field_play_se` (modes 0 always, 1 only when quiet, 2 stop others first).

#### Name mismatches

- `audio_is_sound_id_loaded` (`0x088676d0`): a range check of the id against the header, not a residency test.
- `audio_select_cutin_voices_special` (`0x0984076c`): the selector for generic students (called when `world_character_is_generic` is true).
- `audio_play_track_crossfade` (`0x0886dad0`): starts a sound script and retires the other running scripts (its second argument is a callback for script op 3).
- `audio_set_track_fields_ac_b4` / `audio_get_track_state` (`0x0886d72c`/`0x0886d7a0`): sound-script frame/speed setter and state getter.
- `audio_apply_mix_preset_to_sound` and `audio_push_mix_preset`: also implement pause/resume (mode bit 0).
- `audio_start_atrac_voice` (`0x0886826c`): runs for every new sound object; only types 4-5 touch sceAtrac.
- `audio_find_lowest_priority_channel` (`0x0886a988`): returns the slot of the lowest age rank of a category.
- `audio_get_voice_level` (`0x088698b0`): level meter of the current voice handle `0x08dd3174` (the "voice" is the `audio_play_voice` channel).
- `audio_update_bgm_ducking`: the duck fader applies to every non-sound-effect object (BGM category).

#### Corrections to existing docs

- Fader byte layout (see above): `+0` target, `+2` current.
- `audio_find_or_add_entry` load entries: `+0` read key, `+4` buffer, `+8 u16` bank, `+0x0a` busy, `+0x0c u16` count.
- `audio_release_sas_voice` calls `audio_release_sas_voices(mask, hard)` with a second argument the 2026-10-31 row does not mention.
